# Git

## Commit messages: Conventional Commits 1.0.0

Use the following structure:

```
<type>[optional scope]: <description>

[optional body]

[optional footer(s)]
```

- Use `feat` for a new capability and `fix` for a bug fix. Other accepted
  types are `build`, `chore`, `ci`, `docs`, `style`, `perf`, `refactor`,
  `test`, and `revert`.
- Reuse existing lowercase scopes where practical.
- Write descriptions in the imperative, beginning in lowercase, without a
  trailing period.
- Use `!` before the colon and/or a `BREAKING CHANGE:` footer for breaking
  changes.
- Select the type that best describes the actual change.

## Language

Write commit messages, pull-request titles and descriptions, and GitHub issue
text in English.
